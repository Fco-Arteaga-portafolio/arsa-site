Aviso de Privacidad

Última actualización: Julio 2026

1. Información que recopilamos en Run Run Run

Run Run Run recopila información personal como nombre, correo electrónico, ubicación y datos de actividad física (rutas, distancia, ritmo) para que la aplicación pueda funcionar correctamente y brindar sus servicios a la comunidad runner.

2. Uso de información en Run Run Run

Run Run Run utiliza tu información para proporcionar seguimiento de actividad, conectar con otros corredores, mejorar la plataforma, contactarte sobre actualizaciones y mantener la seguridad de tu cuenta.

3. Protección de datos en Run Run Run

Run Run Run implementa medidas de seguridad avanzadas, incluyendo encriptación de datos en tránsito y en reposo, para proteger tu información personal.

4. Compartir información de Run Run Run

Run Run Run no comparte tu información personal con terceros sin tu consentimiento, excepto cuando es necesario para el funcionamiento del servicio.

5. Tus derechos en Run Run Run

Tienes derecho a acceder, corregir, actualizar o solicitar la eliminación de tu información personal en cualquier momento.

6. Duración de conservación de datos en Run Run Run

Conservamos tus datos mientras tengas una cuenta activa. Si solicitas la eliminación de tu cuenta, todos tus datos se borrarán en un plazo máximo de 20 días hábiles.

7. Consentimiento y aceptación en Run Run Run

Al utilizar Run Run Run, aceptas el tratamiento de tus datos conforme a este Aviso de Privacidad. Si no estás de acuerdo, no debes usar la aplicación.

Para más información contáctanos en contacto@ar-sa.com.mx

Eliminar Cuenta

⚠️ Acción irreversible en Run Run Run

Eliminar tu cuenta de Run Run Run es una acción permanente. Se borrarán todos tus datos, historial de actividad, rutas y configuraciones.

¿Qué sucederá al eliminar tu cuenta de Run Run Run?

  • ✓ Tu perfil de Run Run Run será desactivado inmediatamente
  • ✓ Se eliminarán todos tus datos personales de Run Run Run
  • ✓ No podrás acceder a tu historial de actividad en Run Run Run
  • ✓ Se cancelarán todas tus suscripciones activas en Run Run Run

Proceso para eliminar tu cuenta en Run Run Run

  1. 1. Accede a la configuración de tu cuenta de Run Run Run
  2. 2. Selecciona "Eliminar cuenta" en la sección de privacidad
  3. 3. Confirma tu contraseña para verificar tu identidad
  4. 4. Revisa y acepta los términos de eliminación
  5. 5. Confirma la eliminación de tu cuenta (no hay vuelta atrás)

También puedes eliminar tu cuenta enviando un correo a contacto@ar-sa.com.mx
